Aide, astuces et guides pour WakeUp.

Comment importer votre propre son d'alarme dans WakeUp

  1. Localisez le fichier audio sur votre ordinateur ou dans votre application Musique.
  2. Si vous utilisez l'application Musique, faites un clic droit sur le morceau et sélectionnez Afficher dans le Finder.
  3. Copiez le fichier audio (.m4a, .mp3 ou .wav) dans un dossier iCloud Drive ou transférez-le via AirDrop sur votre iPhone ou iPad.
  4. Sur votre appareil, ouvrez WakeUp → Réglages → Sons personnalisés, touchez Choisir un fichier audio… et sélectionnez le fichier dans l'application Fichiers.
Remarque : Vous devez posséder le fichier audio importé. Seuls les fichiers sans DRM (tels que la musique achetée ou vos propres enregistrements) sont pris en charge. Les morceaux protégés provenant de services de streaming ne peuvent pas être importés.

Je voyage. Que dois-je savoir ?

Lorsque vous changez de fuseau horaire, garder vos alarmes à l'heure est très simple :

  • Les alarmes récurrentes habituelles s'adaptent automatiquement à l'heure locale de votre appareil.
  • Les alarmes avec des exceptions temporaires (comme une prochaine alarme décalée ou une alarme ignorée) sont programmées dans l'AlarmKit d'Apple à un moment fixe dans le temps. Dans l'application, elles sont signalées par une icône d'épingle.

Ce qu'il faut faire : À votre arrivée dans un nouveau fuseau horaire, ouvrez simplement WakeUp. L'application détecte automatiquement le nouveau fuseau horaire et met à jour vos alarmes à l'heure locale.

Afficher le fuseau horaire : Si une alarme est programmée dans un fuseau horaire différent de votre position actuelle, son fuseau horaire s'affiche automatiquement à côté de l'épingle. Si vous souhaitez toujours afficher le fuseau horaire à côté de l'épingle, activez WakeUp → Réglages → Vous changez de fuseau horaire ? → Afficher les détails du fuseau horaire.

Astuce : WakeUp affiche une confirmation dans l'application dès que vos alarmes ont été mises à jour pour le nouveau fuseau horaire.
